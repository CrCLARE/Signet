 # 赞助者

Signet 完全免费、开源。它由一个小编队在业余时间维护。
如果它替你省下了几个小时的工作，欢迎考虑支持这个项目。

## 当前赞助者

完整赞助者名单维护在：

**[crclare.top/reward](https://crclare.top/reward)**

每一份支持——一杯咖啡的钱、一次域名续费、一笔小额捐赠——
都直接用于支持 Signet 以及其他 CrCLARE Studio 项目的持续开发。

## 成为赞助者

赞助通过 CrCLARE Studio 的赞助页面进行。任何金额都欢迎，
特别感谢长期支持。

**→ [赞助 Signet](https://crclare.top/reward)**

### 你的支持会用在哪些地方

- 域名和 DNS 费用
- 测试基础设施
- 设计工具的软件许可
- 维护者的时间

### 展示与致谢

默认情况下，赞助者会以展示名和所选金额的形式出现在赞助页上。
如果你希望匿名，或者想调整展示信息，请联系 `hi@crclare.top`。
