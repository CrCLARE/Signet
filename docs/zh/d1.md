 # 初始化 D1 数据库

Cloudflare D1 是一个分布式 SQLite 数据库。Signet 用它存储用户、订单、
产品、授权和审计日志。

你在上一步已经创建了数据库并推送了表结构。本页解释**创建了什么、为什么这么设计**，
让你在使用前理解数据模型。

## 五张表

### `users`

存储注册账号。

| 列 | 用途 |
|:---|:---|
| `id` | UUID，主键 |
| `email` | 唯一，小写 |
| `nickname` | 显示名（对外公开） |
| `password_hash` | PBKDF2-SHA256 哈希 |
| `password_salt` | 每用户独立的盐 |
| `created_at` | Unix 毫秒时间戳 |

邮箱以小写存储并强制唯一。密码哈希使用 PBKDF2-SHA256 迭代 10 万次——
和管理员密码相同的参数。

### `orders`

存储来自支付渠道的已付订单。

| 列 | 用途 |
|:---|:---|
| `id` | UUID，主键 |
| `order_no` | 支付平台的订单号 |
| `provider` | 适配器名（`afdian`、`stripe`、`manual` 等） |
| `provider_user` | 买家在支付平台的 ID（可选） |
| `provider_raw` | 原始 webhook 载荷（JSON） |
| `amount` | 支付金额，字符串 |
| `status` | `2` 表示已支付 |
| `bound_user_id` | 该订单归属的用户 |
| `bound_at` | 绑定时间 |
| `created_at` | 订单到达时间 |

`(provider, order_no)` 组合唯一。这意味着两个不同渠道的订单号即使碰巧一样，
也不会冲突。

管理员在后台创建的虚拟订单，`order_no` 以 `MANUAL-` 开头，防止有人通过正常
流程去绑定它们。

### `products`

存储用户创建的产品。

| 列 | 用途 |
|:---|:---|
| `id` | UUID，主键 |
| `user_id` | 归属用户 |
| `name` | 产品名 |
| `product_uid` | 授权文件中内嵌的短 ID |
| `created_at` | Unix 毫秒时间戳 |

`product_uid` 就是最终写进授权文件里的东西。16 位大写字符，短，方便在
客服邮件里读出来。

### `licenses`

存储每一次授权签发。

| 列 | 用途 |
|:---|:---|
| `id` | UUID，主键 |
| `product_id` | 对应产品 |
| `user_id` | 对应用户 |
| `fingerprint` | 买家的 user ID（用于溯源） |
| `issued_at` | Unix 秒时间戳 |
| `banned` | 撤销时为 `1` |
| `manual` | 管理员开通时为 `1` |
| `note` | 管理员自由备注 |
| `ban_reason` | 封禁时公开显示的理由 |

注意同一个用户可以对同一个产品多次签发（换机器、重新下载）。
每次签发单独一行。这是有意为之——为了留下审计轨迹。

### `audit_log`

存储每一次管理员操作。

| 列 | 用途 |
|:---|:---|
| `id` | UUID，主键 |
| `admin_id` | 管理员用户名（不是外键） |
| `action` | `ban_license`、`grant_pro`、`admin_reset_password` 等 |
| `target` | 受影响记录的 ID |
| `detail` | 操作相关的 JSON 数据 |
| `created_at` | Unix 毫秒时间戳 |

管理员用户名直接存，不做外键——因为管理员不是 `users` 表里的行，
而是来自环境变量。

## 验证表结构

执行：

```bash
npx wrangler d1 execute signet-db \
  --command="SELECT name FROM sqlite_master WHERE type='table' ORDER BY name;" \
  --remote
```

预期输出：

```
_cf_KV
audit_log
licenses
orders
products
users
```

六张都看到就没问题。

查看某张表

看任意表的结构：

```bash
npx wrangler d1 execute signet-db \
  --command="PRAGMA table_info(users);" \
  --remote
```

查询数据

可以通过 wrangler 跑任何 SQL。例如：

```bash
# 统计注册用户数
npx wrangler d1 execute signet-db \
  --command="SELECT COUNT(*) FROM users;" \
  --remote

# 列出最近 10 笔订单
npx wrangler d1 execute signet-db \
  --command="SELECT order_no, provider, amount, created_at FROM orders ORDER BY created_at DESC LIMIT 10;" \
  --remote
```

也可以在 Cloudflare 控制台的 D1 Console 里查——有图形界面，临时查询更方便。

备份

D1 免费套餐没有自动的时间点恢复。关键数据建议定期导出：

```bash
npx wrangler d1 export signet-db --output=backup.sql --remote
```

把文件存到安全的地方。灾难恢复：

```bash
npx wrangler d1 execute signet-db --file=backup.sql --remote
```
