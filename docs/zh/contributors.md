## 如何贡献

我们欢迎各种形式的贡献——代码、文档、翻译、Bug 报告和设计。

提交 PR 之前，请阅读仓库里的
[CONTRIBUTING.md](https://github.com/CrCLARE/Signet/blob/main/CONTRIBUTING.md)。

### 快速指南

1. **先开 Issue** —— 除了显而易见的修复，其他都建议先开 Issue。
   这能避免重复劳动。
2. **一次改动一个 PR。** 保持 PR 聚焦。
3. **写清楚的提交信息。** 描述*为什么*，不只是*做了什么*。
4. **加测试** —— 如果你加了新的后端逻辑。
5. **更新文档** —— 如果你改了行为。

### 我们特别希望得到帮助的方向

- 更多支付适配器（Stripe、Paddle、Gumroad）
- 更多人机验证适配器（Google reCAPTCHA、极验）
- 其他语言的翻译
- 自动化测试覆盖
