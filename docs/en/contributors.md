## How to contribute

We welcome contributions of all kinds — code, documentation, translations,
bug reports, and design.

Before submitting a pull request, please read
[CONTRIBUTING.md](https://github.com/CrCLARE/Signet/blob/main/CONTRIBUTING.md)
in the repository.

### Quick guidelines

1. **Open an issue first** for anything beyond trivial fixes. This avoids
   duplicated effort.
2. **One change per pull request.** Keep PRs focused.
3. **Write clear commit messages.** Describe the *why*, not just the *what*.
4. **Include tests** if you add new backend logic.
5. **Update documentation** if you change behavior.

### Areas we'd love help with

- Additional payment adapters (Stripe, Paddle, Gumroad)
- Additional captcha adapters (Google reCAPTCHA, Geetest)
- Translations into other languages
- Automated test coverage
