Apache 2.0 · v1.0 release · Cloudflare Workers + D1

What it does

Everything you need to run a licensed product — nothing you don't

User accounts

Registration, login, and admin-triggered password resets. PBKDF2-SHA256 password hashing out of the box.

Order binding

Connect a payment order to a user account. Pluggable adapters — Afdian included, add your own in ~50 lines.

Offline license issuance

Sign licenses with Ed25519. Once issued, they work forever — no server round-trip required to verify them.

Admin dashboard

Search licenses, ban/unban with reasons, grant Pro access to any user, audit every action. Independent admin credentials.

Public lookup

Anyone can verify a product's license status without logging in. No emails, no order numbers, no personal data exposed.

Zero-Trust design

It's open source with no black boxes, so you have full control over all the logic and keys yourself.
